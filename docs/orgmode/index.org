* Overview

~hzArchiso~ builds a custom Arch Linux live image (~hzLinux~) and ships a
*native Go* installer (~hz-install~ / ~hz-install-tui~) for encrypted Btrfs
machine installs with Sway and chezmoi bootstrap.

This tree holds Org sources in the same spirit as LODE/readcon-core
~docs/orgmode~: sectioned =#+title= documents with copy-paste command blocks.
