#+title: Hardware manifest and profile rationale
#+options: toc:2 num:t

* Purpose

This document is the *hardware contract* for **all** hzArchiso / linux-rg
machine profiles. Every supported install profile has a full section here:

| Profile | Machine | Form |
|---------|---------|------|
| ~rgx1gen11~ | Lenovo ThinkPad X1 Carbon Gen 11 (21HM002GUS) | Ultrabook (verified daily driver) |
| ~rgSURFLat~ | Dell Latitude 7430 | 14" business laptop / 2-in-1 family |
| ~rgam5terra~ | Fractal Terra SFF + AM5 + RTX 5070 | Mini-ITX desktop (receipt-backed) |

Tables record exact (or factory option-matrix) hardware, why packages/kernel
pins exist, and what to probe on the unit. Installer deltas
(=installer/hz-install-tui/install/packages.go=) and linux-rg overlays
(=LINUX_RG_PROFILE=…) must stay consistent with these sections.

Cross-repo detail (drivers, boot safety, patch matrices) lives under the
matching =docs/${slug}-*.org= files in the **linux-rg** repository.

Related hzArchiso docs: [[file:profiles.org][profiles.org]], [[file:installer.org][installer.org]],
[[file:getting-started.org][getting-started.org]].

** Package / kernel rationale (rgam5terra)

| Hardware need | Installer | Kernel / overlay |
|---------------|-----------|------------------|
| Zen 5 CPU | =amd-ucode= | Arch base; **0022 znver5 RDSEED** only on this profile |
| RTX 5070 | =nvidia-open-dkms=, =nvidia-utils=, =nvidia-settings=, =opencl-nvidia= | open module + firmware; modprobe =rgam5terra-nvidia.conf= |
| Desktop power | =tuned=, =tuned-ppd= (not TLP) | — |
| Remove laptop stack | Drop =tlp=, =tlp-rdw=, =thermald= | No ThinkPad/Dell laptop ACPI as primary |
| Memory / NVMe / thermals | =nvme-cli=, sensors via userspace | checkers =rgam5terra-*-check= |
| Explicitly *out* | No =intel-ucode= delta, no Iris-only media stack as primary GPU path | No iwlwifi AX211 contract |

** Thermal / SFF rationale

Terra + NH-L9a on 9950X + ~250 W-class GPU is a **tight thermal envelope**.
Userspace power limits (PPT, EPP, GPU power) matter as much as scheduler
patches. Prefer measured policy over blind CachyOS desktop defaults.

* Maintenance

1. Change hardware → update **this file** and the matching linux-rg
   =docs/${slug}-targets.org=.
2. New *class* of device (e.g. dGPU in a laptop) → **new profile**, not a silent
   package append on an existing slug.
3. Re-run =make tui-check= and linux-rg =scripts/linux-rg-profile-selftest=.
